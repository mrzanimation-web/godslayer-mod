### ✨ Animations & Particles (EVERY FORM IS ANIME)
- Ring slash + forward dragon trail, electric sparks (Thunder), flame, splash, wind, mist clouds, dragon breath for ultimates
- Thunder = dash 2.5 blocks + lightning sound
- Water Dead Calm = resistance bubble
- GOD = SOUL_FIRE nuke + explosion + strength
- Switch breathing = END_ROD burst
- Sounds per breathing (dolphin splash, blaze, lightning etc)

### 🎮 Controls
- **R** = Next Breathing (Shift+R = Prev)
- **V** = Next Form (Shift+V = Prev)
- **Right Click (sword)** = EXECUTE current Form - damages mobs in radius, knocks back, applies element (fire, slow, etc) + particles
- **G** = Toggle GOD MODE (Resistance V + Regen + Speed, 3x damage, golden HUD)
- After execute, auto-advances to next Form for combo!
- 2-sec cooldown (1s for God)

### 🖥 HUD
Top center anime banner: Breathing Name + Japanese + Form name + breathing gauge bar. Bottom left key hints. GOLD blink when God Mode.

## Install
1. Install Fabric Loader 0.16.10 for 1.21.11 + Fabric API 0.119.0
2. Put `godslayer-1.0.0.jar` in `mods/`
3. Launch. Press R/V/G. Enjoy.

## Build from source
```powershell
# needs Gradle 8.10 + JDK 21
gradle build
# jar in build/libs/godslayer-1.0.0.jar
```

## Customise God Stats
Edit `GodSwordItem` / `GodToolItem` -> change damage/speed/reach/miningSpeed, rebuild. Or use commands to `/attribute`.
